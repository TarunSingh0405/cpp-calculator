 # C++ Calculator

## About the Project
This is my first C++ programming project. It is a simple calculator that performs basic arithmetic operations based on user input.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Displays results up to five decimal places.
- Uses switch-case statements to select operations.

## Concepts Used
- Variables and data types
- User input and output (`cin` and `cout`)
- Arithmetic operators
- Switch-case statements
- Output formatting using `iomanip`

## How to Run

Compile the program using GCC:

```bash
g++ calculator.cpp -o calculator
```

Run on Windows:

```bash
.\calculator.exe
```
